# JobFinder - Midterm Project

A fully responsive, multi-page job portal web application developed as a Midterm Project for Web Technologies.

##  Project Overview
**JobFinder** is a modern platform connecting job seekers with top employers. The project implements comprehensive frontend development principles, clean semantic structures, and user-friendly UI/UX design.

##  Pages Included
1. **`index.html` (Home):** Landing page featuring a hero search section and popular job categories.
2. **`jobs.html` (Find a Job):** Job listings page incorporating an interactive summary table for comparing positions and salaries.
3. **`companies.html` (Companies):** Directory showcasing top partner companies and their open roles.
4. **`post-job.html` (Post a Job):** Interactive form allowing employers to publish new job vacancies.
5. **`contact.html` (Contact Us):** Support page containing a fully structured communication form.

##  Technologies Used
- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), tables, and forms.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and Sticky Positioning.
- **Responsive Design:** Custom media queries ensuring full adaptability for mobile devices and tablets.

##  How to Run Locally
1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Use the **Live Server** extension to open `index.html` in your browser.
